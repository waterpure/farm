# V45 每种紧俏商品 70% 购买目标审计 v1

## 用户规则

对每一种紧俏商品分别计算，而不是分配土地比例：

```text
目标产量 = 当前已开商店在剩余时间会购买的数量 × 70%
缺口 = 目标产量 −（已有生产 + 已承诺路线未来会收获的生产）
```

达到目标便停止增加该商品；新增能力优先填另一个紧俏商品的缺口，全部填满后才考虑非紧俏高价值线。

## 本轮只读测试

`lab/target_coverage_audit.py` 读取已验证的逐日收获重放 `experiments/v45_route_supply_demand_audit_v3.json`。这份审计故意使用**赛后真实收获量**，目的不是实时选 route，而是先验证规则本身会不会接受先前已知的错误切换。

已开店每天购买超过 Town Center 基础 1 份的商品视为紧俏；比较 candidate 与冻结 V45 原 route 对每种紧俏货的：

- 离 70% 目标还差多少；
- 是否已经达到目标；
- candidate 是否又增加了已达标商品的超额产量。

若 candidate 没有填补任何新缺口，却增加已达标紧俏商品的超额生产，拒绝 candidate、保持 V45。
