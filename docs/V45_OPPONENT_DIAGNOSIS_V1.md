# V45 × 七对手根因诊断 v1

## 范围与可信度

这不是策略改动或官方 leaderboard 评估。它重跑固定 development 条件：7 个公开本地对手 × seeds `0–3` × V45 左右座位，共 56 局。逐回合 trace 保存当前公共农场/市场、双方私有库存，以及刚执行的市场/单位动作。

所有 56 局终局现金与冻结联赛 `experiments/seven_opponent_league_v1.jsonl` 完全一致，故全部纳入聚合。原始 trace 为 `experiments/v45_opponent_diagnosis_v1.jsonl`，机器可读汇总为 `experiments/v45_opponent_diagnosis_v1_summary.json`。

阶段定义：开局 `0–72`、发展 `73–287`、市场 `288–647`、终局 `648–719`。下表的“阶段现金差”是该阶段内 V45 现金变化减去对手现金变化；正数有利 V45。它是已实现的现金结果，不是对某一条市场订单的因果归因。

## 结论先行

V45 有两种非常不同的对局类型：

1. 对 `sdy2842`、V46、`nathan_pipe7`，双方到第 287 和第 647 回合的雇工、作物、动物、可产出量几乎相同。差距主要是市场订单/现金路径，而不是“V45 少养了牲畜”或“路线没展开”。
2. 对 `indar_top10`、`kaito_v58`、`boatlee_v16`、`indar_pasture`，V45 到第 287 回合已通常多出约 `3.5–5` 头动物；中后期的生产与变现扩大成数万现金优势。这是 V45 强生产/终局回收层的适用区，不应为了克制近亲而破坏。

因此，下一条原创策略不应再是泛化的“扩大提前卖货窗口”：V45 已有很强的卖货预留/前置层，且对 sdy 时该层高度活跃仍输。需要定位**市场现金路径的具体分叉**，特别是开局小麦互换与中段共享市场报价，而不是继续叠加历史卖货补丁。

### 近亲劣势：生产没有分叉，现金先分叉

`sdy2842`：第 0 回合 V45 请求 `BUY/SELL WHEAT 70/70`，sdy 请求 `10/10`。第 1 个状态 V45 在代表条件中已落后 108 现金，日 1 末仍落后 28；平均而言发展段再失 1,262.5，最终 -2,001.1。到发展和市场段结束，双方平均雇工、作物、动物、可产出量均相同；V45 的 `race_clone_turns=476`、`sale_reserved_units≈253`、`race_escalations=1`，说明 V45 的近亲竞速/预卖保护实际已经在运行。**可支持的解释**是：sdy 的市场微结构与现金时序更占优；不能把全部差额仅归因于第 0 回合 70 对 10，因为 sdy 还有其它公开 wrapper 差异。

`nathan_pipe7`：第 0 回合为 `70/70` 对 `5/5`。平均差在开局为 -12、发展为 -224.5，之后市场和终局的平均增量都是 0；发展/市场结束时双方生产资产完全相同。这是最干净的“早期市场现金细差被路线锁定”的证据，但样本仍只有 8 条条件。

V46：第 0 回合是 V45 `70/70` 对 V46 `BUY 7, SELL 2`。V45 在开局/发展分别 -14/-143，市场段再 -404.8，但终局收回 +126.2；关键生产资产边界仍相同。说明 V46 的优势更集中于中段市场执行，而 V45 的终局层能部分对冲它；还不足以定位为某个具体卖单。

这些数值是状态相关而非单独因果证明，但模式跨四个异质对手一致：V45 的既有生产路线在第 287 回合前建立更多动物资产，再将其转为中后期现金。它解释了为何 V45 不适合被 V46/sdy 的完整市场包替代。

## 不能从数据得出的结论

- trace 内的市场 `SELL` 数量是 agent 请求量，不等于逐单位成交量；不能把它当实际销售收入。
- 共享市场、店铺需求和双方动作相互影响；阶段现金差不自动证明“某个订单导致差额”。
- 双座位条件是不同的共享市场路径，但不是独立随机样本；7 个本地公开对手也不代表正式 Kaggle 人群。

## 下一道研究门

在提出任何新策略前，应该为三个近亲对手做**分叉回合级**审计：找到现金差首次超过固定阈值的回合，并结合该回合双方订单、市场库存/价格变化和后续 1–4 回合现金变化，区分开局小麦互换、店铺结算、提前卖货与资金约束。只有出现跨 seeds/seat 重复的事件模式，才设计一个原创的、条件化市场规则。

该研究门已按原始 trace 完成，结果见 [V45_NEAR_PEER_DIVERGENCE_V1.md](V45_NEAR_PEER_DIVERGENCE_V1.md)。它将持久性窗口扩至 24 个状态，并在严格可识别的 sell-only 情况下反解实际成交量；结论是优先检查 worker 级库存交接，而不是泛化扩大提前卖货窗口。
